\begin{block}{Eviction Forgets, Low-Rank Blurs}
At matched memory (Mistral-7B, Qwen2.5-14B, 4K context):
\vspace{0.2cm}
\begin{itemize}
  \item \textbf{Eviction} (StreamingLLM) wins perplexity (+1.0\%) but can never recall an evicted token.
  \item \textbf{Low-rank} (frozen basis, TKV) keeps every token but costs +5--6\% perplexity, and recalls some evicted facts.
\end{itemize}
\vspace{0.2cm}
Why low-rank blurs the wrong tokens: an SVD basis keeps the directions
\emph{shared} by many tokens. A token that carries new information is exactly
one the basis explains poorly.
\takeaway{The tokens worth remembering are the ones\\ with the largest projection residual.}
\end{block}

\begin{block}{TKV-R: Residual-Guided Retention}
\begin{center}
\begin{tikzpicture}[x=1cm,y=1cm]
  \fill[navy!85] (0,0) rectangle (2.4,2.2);
  \fill[oja!70] (2.4,0) rectangle (16.2,2.2);
  \foreach \x in {4.1,6.9,7.6,11.3,13.8} {\fill[accent] (\x,0) rectangle (\x+0.55,2.2);}
  \fill[good!75] (16.2,0) rectangle (23,2.2);
  \node[white,font=\small\bfseries] at (1.2,1.1) {sinks};
  \node[white,font=\small\bfseries] at (9.3,-0.7) {};
  \node[white,font=\small\bfseries] at (19.6,1.1) {recent window};
  \node[font=\small,color=oja!60!black] at (9.3,-0.75) {middle: rank-$R$ coefficients};
  \node[font=\small\bfseries,color=accent] at (9.3,2.9) {top-$M$ residual tokens kept exact};
\end{tikzpicture}
\end{center}
\vspace{0.2cm}
\begin{itemize}
  \item Freeze a rank-$R$ basis $B$ after a 512-token warmup (fit \textbf{pre-RoPE}).
  \item Each token leaving the window: store $c = Bk$ and its residual $\rho = \lVert k - B^\top c\rVert$.
  \item A \textbf{min-heap of capacity $M$} keyed by $\rho$ keeps the top-$M$ residual tokens exact; the loser keeps only $c$. Cost: $\mathcal{O}(Rd + \log M)$ per token.
  \item Budget = rank $R$ + window $W$ + $M$ exact tokens, matched byte-for-byte to eviction.
\end{itemize}
\end{block}

\begin{block}{A Guarantee for Every Future Query}
RoPE is a rotation, so for any query $q$ and compressed key $j$:
\[
\bigl|q^\top \mathcal{R}_j k_j - q^\top \mathcal{R}_j \hat k_j\bigr| \le \lVert q\rVert\,\rho_j .
\]
With $\varepsilon = \alpha\lVert q\rVert\max_{\text{compressed}}\rho_j$, attention weights move by
$\lVert p - \hat p\rVert_1 \le e^{2\varepsilon} - 1$. Keeping the top-$M$ residuals
\textbf{minimizes this bound for all queries at once}: no need to know which
queries will come, unlike attention-score eviction.
\end{block}

\begin{block}{Corrections Along the Way}
\begin{itemize}
  \item \textbf{Brand warmup.} Truncated updates are optimal only for the \emph{retained state + new token}, not the full history. Valid online certificate: $\lVert E_t\rVert_F \le \lVert E_{t_c}\rVert_F + \sum_s \sigma_{R+1}(A_s)$.
  \item \textbf{Pre-RoPE bases}: post-RoPE costs 2$\times$ the perplexity (+11.5\% vs.\ +5.6\% Mistral; +10.1\% vs.\ +5.3\% Qwen).
  \item \textbf{Oja baselines}: storing coefficients in the arrival-time basis but reconstructing with the final one gave errors above 1.0. Fixed, OjaKV ties TKV within 0.5\%.
\end{itemize}
\end{block}

\begin{block}{Limits}
\begin{itemize}
  \item 2K--4K context; 30 windows / 15 needle prompts per cell; single needle format (no RULER / LongBench yet).
  \item Gains are model-dependent (none on Qwen2.5-14B retrieval).
  \item Exact-SVD warmup; heap simulated in a teacher-forced pass; no quantization or SnapKV baseline.
\end{itemize}
