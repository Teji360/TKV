# Superseded drafts

These are earlier versions kept for provenance. **Do not cite them.**

`TKV_preaudit_RETRACTED.pdf`, `TKV_preaudit_submission_RETRACTED.pdf`,
`TKV_preaudit.tex`, `TKV_poster_preaudit.tex` predate the September 2026 audit and
contain claims we have since withdrawn:

- a per-token Eckart--Young--Mirsky optimality guarantee for truncated Brand
  updates, which is false (see Prop. 3 of the current paper for the correct,
  weaker statement);
- Mistral-7B perplexity numbers measured on 80 tokens of five short sentences,
  where the method never reached its freeze point;
- an OjaKV baseline with a stale-coefficient bug that inflated its error above
  that of storing zeros.

The later archived drafts (`*_fair_eval_v2.tex`, `*_tkvr_v3.tex`) are honest but
superseded by the current `paper/TKV.tex`.
